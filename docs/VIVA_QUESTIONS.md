# Viva Questions and Answers

1. **What is MERN?** MongoDB, Express.js, React.js and Node.js form a JavaScript full-stack technology stack.
2. **Why React?** It supports component-based interfaces and client-side routing.
3. **What is Vite?** A modern frontend development server and build tool.
4. **What is Node.js?** A JavaScript runtime built on the V8 engine.
5. **What is Express?** A minimal framework for Node.js HTTP servers and APIs.
6. **What is MongoDB?** A document-oriented NoSQL database.
7. **What is Mongoose?** An ODM that provides schemas, validation and model operations for MongoDB.
8. **What is a REST API?** A resource-oriented HTTP interface using methods such as GET, POST, PUT and PATCH.
9. **What is JWT?** A signed token format used to carry claims between client and server.
10. **Why hash passwords?** Hashing protects stored credentials if the database is exposed; passwords should not be stored in plaintext.
11. **What is bcrypt?** A password-hashing function designed to be computationally expensive.
12. **What is middleware?** A function in the request-response pipeline that can inspect, modify or end a request.
13. **What is role-based access control?** Restricting actions according to a user's assigned role.
14. **What is Multer?** Express middleware for handling multipart file uploads.
15. **Why validate uploads?** To reduce invalid or unsafe files and enforce size/type limits.
16. **What is PDF parsing?** Extracting text and metadata from PDF documents.
17. **What is Mammoth?** A library that extracts raw text from DOCX files.
18. **What is NLP?** Techniques that enable computers to process and analyze human language.
19. **What is tokenization?** Splitting text into smaller units such as words or tokens.
20. **What are stop words?** Common words often removed when they contribute little to a particular text comparison.
21. **What is normalization?** Converting equivalent terms or text forms into a consistent representation.
22. **What is a skill dictionary?** A curated list of skill terms and aliases used for extraction and matching.
23. **What is TF?** Term frequency measures how often a term appears in a document.
24. **What is IDF?** Inverse document frequency reduces the weight of terms common across documents.
25. **What is TF-IDF?** A weighting method combining term frequency and inverse document frequency.
26. **What is cosine similarity?** A measure based on the cosine of the angle between two vectors.
27. **Why use cosine similarity?** It compares document vectors while reducing sensitivity to vector magnitude.
28. **What is weighted scoring?** Combining multiple normalized criteria using chosen weights.
29. **Why explainable AI?** Users should understand which evidence and components contributed to an output.
30. **Is the score a hiring decision?** No. It is decision support; recruiters must verify evidence and make decisions.
31. **Why MongoDB?** Its document model maps naturally to user, job, resume and application records.
32. **What is a Mongoose schema?** A definition of document fields, types, validation and options.
33. **What is an index?** A database structure that can speed up queries and enforce uniqueness.
34. **How are duplicate applications prevented?** A compound unique index on candidateId and jobId, plus an API error response.
35. **What is CORS?** A browser security mechanism controlling cross-origin requests.
36. **Why Helmet?** It sets security-related HTTP headers.
37. **Why rate limiting?** It limits repeated requests and can reduce abuse.
38. **What is environment configuration?** Keeping deployment-specific settings and secrets outside source code.
39. **What is responsive design?** Layouts that adapt to different screen sizes and devices.
40. **What is an integration test?** A test that verifies multiple parts work together, such as API, database and authentication.
41. **What are the limitations?** Scanned PDFs need OCR; extraction and experience matching are heuristic; lexical similarity may miss semantic equivalence.
42. **How could the AI be improved?** Add contextual embeddings, better entity extraction, OCR and careful evaluation on consented data.
43. **How can bias be reduced?** Exclude sensitive attributes, audit outcomes, use consistent job criteria and keep human oversight.
44. **Why is human review important?** Resume content may be incomplete or incorrectly parsed and a numeric score cannot represent a whole candidate.
45. **What is the future scope?** Secure cloud file storage, OCR, semantic matching, audit trails, notifications and accessibility improvements.
