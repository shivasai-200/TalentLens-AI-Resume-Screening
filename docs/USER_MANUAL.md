# User Manual

## Start the application
Follow the root README to configure MongoDB, install packages and start both servers.

## Recruiter workflow
1. Register with account type Recruiter.
2. Sign in and open the workspace.
3. Select Create a job and provide title, company, description and required skills.
4. Share the active job listing with candidates.
5. Open Candidate applications to inspect job-specific match scores and evidence.
6. Change an application stage using the status selector.
7. Review aggregate counts on Analytics.

## Candidate workflow
1. Register with account type Candidate.
2. Sign in and upload a text-based PDF or DOCX resume.
3. Review extracted profile details.
4. Browse active jobs and open a job detail page.
5. Apply. The application uses the latest uploaded resume.
6. Track progress in the candidate dashboard.

## Understanding the score
The score is a heuristic comparison of declared job criteria and resume text. Inspect matched/missing skills and component breakdown. Extraction may miss information; verify it manually. A score is not a measure of a person's overall ability and must not be used as the sole basis for rejection.
